# Anthropic

AI 公司,Claude 系列模型的开发者。在 [[mcp-explained]] 的语境中,MCP([[ModelContextProtocol]],模型上下文协议)由 Anthropic 推出——一个连接大型语言模型与外部工具、数据源和应用系统的开放协议,被类比为"AI 应用的 USB-C 接口"。

## 关键事实

- 推出了开放协议 MCP,标准化模型获取上下文与执行操作的方式
- 其产品 Claude Desktop 属于 MCP Host(启动 LLM 连接的应用程序)的典型实例
- MCP 官方资源:github.com/modelcontextprotocol、modelcontextprotocol.io
